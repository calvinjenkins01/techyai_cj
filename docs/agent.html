Build your morning agent 🌅

From @techyai_cj. Every morning at 6am my phone gets a brief for the day and I'm asleep when it happens. Here's how to build your own version in one sitting. No coding. Start with the easy path, and the way I actually run mine is at the bottom if you want to go further.

The easy path · scheduled tasks

this is the one to do first

1. Open Claude and make a Project first. Call it something like Morning Brief. Drop in anything it should know about you: what you're working on, your goals, your schedule if you have it written down anywhere.

2. Look for scheduled tasks. It's in the Claude app and it's still in beta, so if you don't see it yet, skip to the no waiting version below.

3. Create a task. Name it Morning Brief, point it at your Project, and set it to run daily at whatever time you actually wake up.

4. Paste this as the task prompt:

the prompt

Give me my day in under 150 words. Start with anything time sensitive I need to handle today. Then my top three priorities based on what I'm working on. Then one thing I've been putting off that I should just knock out today. Write it like a text from a friend, not a report. No greeting, no sign off, just the brief.

That's it. It runs while you're asleep and the brief is waiting when you wake up.

If you connected your calendar or email

this version is noticeably better
the upgraded prompt

Check my calendar for today and my unread email. Give me my day in under 150 words. Lead with anything time sensitive or anything I need to prepare for before it happens. Then my top three priorities. Then flag anything in my inbox that looks like it will become a problem if I ignore it. Write it like a text from a friend, not a report.

Connectors live in Settings, then Connectors. Gmail and Calendar are the two worth turning on for this.

No waiting version

works today, on any plan, takes four minutes

1. Make the Project above and paste the prompt into it once so it's saved.

2. Set a repeating alarm or reminder on your phone for your wake up time.

3. When it goes off, open the Project and send one word. Go.

Not technically an agent, it's a habit with a saved prompt. But it gets you 90 percent of the value while you wait for scheduled tasks, and the Project you built carries straight over when you upgrade.

Other things worth scheduling

01

A Friday summary of what you got done this week, pulled from your own notes.

02

A Sunday planner that sets your three priorities for the week ahead.

03

A monthly check that reads your numbers and tells you the one thing to change.

Rule of thumb: if it repeats on a calendar and has clear steps, an agent can own it. If it needs judgment every time, it can't yet.

How mine actually works

the developer version, only if you want it

Mine is not the app version. I keep a schedule file in a GitHub repo, a free scheduled job rewrites a text file every morning, and an iPhone Shortcut fetches that file at 6am and texts it to me. It's more moving parts, and the only reason I built it that way is that I'm a software developer and I wanted the brief to pull from my own content calendar. If you're starting today, do the easy path. It gets you the same feeling for a fraction of the work.
