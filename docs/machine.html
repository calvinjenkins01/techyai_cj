The content machine ⚙️

From @techyai_cj. I'm a software developer, and my whole posting workflow is one phone take handed to Claude Code. It cuts the footage, builds every format, writes the captions, and ships a page like this one. Here is the machine, station by station, and the first piece worth building yourself.

Claude Code docs: code.claude.com →

The five stations

each one is Claude Code running scripts in one repo
01 — The cut
Transcribes every take locally (faster-whisper), proposes the cuts as a reviewable plan, then applies them: fillers, pauses, retakes, even frames where I look away. ffmpeg does the actual cutting; captions are rebased automatically so nothing drifts.
02 — Frame QC
Face-crop contact sheets of the whole cut, checked frame by frame. The transcript can't see a dropped eyeline or a blink held too long — the frames can. Cuts get verified the same way before anything renders.
03 — The formats
One master cut becomes six versions — from my terminal-card look to real screen captures in browser chrome. Each format is HTML that renders to video (HyperFrames), so a change is a code edit, not a re-edit.
04 — The package
Captions for TikTok and Instagram with the keyword line first, cover frames, and the paste-ready DM reply for whoever comments the keyword.
05 — The guide page
Every keyword points at a real page on this site, built and pushed live in the same run. You are reading station five right now.

Build station one first

the highest-leverage hour you can spend

1. Install Claude Code and open an empty folder. That folder becomes your machine.

2. Ask it to build a cut pipeline: transcribe with faster-whisper, propose cuts as a reviewable list, apply with ffmpeg. Make it show you the plan before it cuts — that review step is the difference between an assistant and a slot machine.

3. Write a preferences file. Every correction you give it goes in there once, and it reads the file every run. That is how "edit it, you know the drill" becomes a real instruction.

4. Only then add stations: formats, captions, covers. One station at a time, on real footage.

The machine is not an app you can download — it is a repo that grows around how you actually work. Mine took shape one correction at a time.
