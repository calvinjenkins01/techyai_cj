Claude forgets everything 🧠

From @techyai_cj. If you're re-explaining your project every morning, you're doing by hand the part it's supposed to remember. Two minutes, once.

01 · Turn memory on

one switch, do this first

Memory lets Claude carry what it learns about you between chats. Without it, every conversation starts from zero and you burn the first five messages getting it up to speed.

WHERE: Settings, find Memory, switch it on. Then ask “what do you remember about me” any time you want to check.

02 · Write the thing down once

the part people skip

Memory picks things up as you go, but the fastest way is to just tell it everything at the start, deliberately, one time.

Paste this and fill it in:

Remember this about my current project so you have it in future chats. Project: [what it is]. Goal: [what done looks like]. Stack or tools: [what you're using]. What I've already tried: [the dead ends, so you don't suggest them again]. Constraints: [budget, time, skill, anything fixed]. How I want you to help: [review my work / write drafts / ask me questions / all of it].

03 · Use a Project for anything ongoing

stronger than memory for real work

A Project is a folder with its own instructions and its own files. Everything in it applies to every chat inside it, and only inside it. Job hunt, side business, a class, planning a trip. Files go in once.

WHERE: Projects in the sidebar, then New Project. Put the instructions in the Project, not your global profile, so they don't leak into unrelated chats.

04 · Test the cold start

how you know it worked

Open a brand new chat and don't explain anything. Just ask something that needs context.

Try this in a fresh chat:

Without me explaining anything: what am I currently working on, what have I already tried, and what would you suggest I do next? If you don't actually know, say so instead of guessing.

05 · Clean it out occasionally

stale memory is worse than none

When a project ends, tell it. Otherwise it keeps giving you advice for something you finished three months ago, which feels exactly like the model getting worse.

Every month or so:

List everything you remember about me and my projects. Flag anything that looks out of date. I'll tell you what to drop.

Free plan handles memory and Projects.

If you only do one thing: write the project description down once, deliberately. That single paste saves more time than everything else here combined.
