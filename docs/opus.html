What the new Claude does differently 🧠

From @techyai_cj. Anthropic released Claude Opus 5 on July 24. These are five things it handles that the older models struggled with, each with the exact prompt to test it yourself. Tap copy, paste into Claude, see for yourself.

01 · It reads your whole project first

the one from the video

Older models needed you to paste one file at a time, so they never saw how your project fit together. Now you point it at the whole folder and it reads everything before it writes a line. That's why it matches the code you already have instead of inventing its own style.

Try it: open Claude Code, point it at a project folder, and ask for a feature in one sentence. Watch it read before it writes.

02 · Spreadsheets that actually calculate

not a picture of a spreadsheet

Ask for a tracker and you get a real multi sheet file with working formulas, not a table you have to rebuild yourself.

Copy this prompt:

Build me a monthly budget spreadsheet as an xlsx file. One sheet for income, one for expenses by category, and one summary sheet that pulls from both with real formulas. Include 3 example rows in each so I can see how it works, and one cell that shows what I have left over this month.

03 · Slide decks that look designed

the trick is design rules, not asking for slides

Asking for "a presentation on X" gets you corporate template soup. Giving it design constraints up front gets you something that looks like a studio made it.

Copy this prompt:

Make me a 6 slide presentation on [topic] for [audience]. Design rules: one idea per slide, huge readable text, absolutely no bullet point soup. Dark background, one bright accent color, generous white space. Slide 1 is a hook that makes them want slide 2. Slides 2 through 5 each make exactly one point backed by a number or a concrete example, and at least one slide must use a simple chart or diagram instead of text. Slide 6 is a single clear takeaway. Make it look like a design studio made it, not a corporate template.

04 · It reads charts and screenshots properly

the numbers, not a guess at the numbers

Screenshot a graph, a receipt, a dense document, or a dashboard and it pulls the actual values out instead of describing what it thinks it sees.

Copy this prompt and attach any screenshot with numbers in it:

Read this image and pull out every number you can see, with a label for what each one is. Then tell me the one thing in here I should actually pay attention to, and why. If anything is unclear or cut off, say so instead of guessing.

05 · It checks its own work

stop telling it to double check

This one is backwards from what you'd expect. On the older models the advice was to tell it to verify its answer. On this one that instruction makes it slower and more repetitive, because it already verifies on its own. Take those lines out of your prompts.

Try it: take a prompt you use that ends with "double check your work" and run it once with that line and once without. The version without is usually tighter.
