5 Claude Code commands 💻

From @techyai_cj. Five commands most people never touch, and the part nobody explains: when to actually use each one. You do not need to know how to code for any of this. Type / on an empty prompt to see everything else you have.

/context

see what is eating your window

Shows a colored grid of what is filling your context window right now, plus suggestions on what to cut. Add all after it for the full breakdown.

WHEN: the second Claude starts forgetting things you already told it, or answers get vague. That is not the model getting dumber, that is your window filling up. Run this before you start over from scratch.

/rewind

the one that saves you

Rolls your code and the conversation back to a checkpoint. Not undo on one file. The whole thing, both at once.

WHEN: it went sideways three steps ago and you do not want to untangle it. Stop arguing with it, rewind and re prompt from before the mess.

/plan

look before it leaps

Switches into plan mode, so it tells you what it is about to do before it touches anything.

WHEN: any change bigger than one file. This is the single best habit if you are nervous about letting it loose in a project you care about.

/clear vs /compact

both free up space, they are not the same

/clear starts a brand new conversation with nothing in it. /compact summarizes what you have done so far and keeps going in the same one.

WHEN: starting a different task, use /clear. Same task but it has been running long, use /compact. Using /clear mid task throws away context you still need.

/init and /memory

set your rules once

/init creates a CLAUDE.md file for your project. /memory edits it later. Whatever rules you put in there, it reads and follows every single session, forever.

WHEN: the first time it does something you never want it to do again. Add the rule instead of correcting it twice.

My starter rules for that file, with a copy button, are on the Claude Code guide along with the exact first thing to build if you are new to it.
