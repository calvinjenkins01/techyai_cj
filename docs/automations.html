25 Claude automations 🤖

From @techyai_cj. Everything on this list is buildable in a weekend, most in an evening. The ✓ running on mine tags are real: those four run on my machine today, and each links to the full guide. Start with exactly one. Mine started with the morning text.

Mornings

01 Your day, planned, sent to you before you wake up
A scheduled task reads your calendar and notes, writes a brief, delivers it. The whole build, no coding: the morning agent guide.
02 Inbox triage, the two emails that matter pulled out
Connect Gmail, schedule one prompt that pulls out only what needs you. The filter prompts: the inbox brief guide.
03 A text with your checklist for the day ✓ running on mine, six am
Mine writes a text file on a schedule and an iPhone Shortcut texts it to me at six. The simple version is the morning agent guide with SMS as the delivery.
04 Weather and commute in one line before you leave
Add weather to the morning brief prompt: one line, leave time, umbrella yes or no. Works inside automation 01, not as a separate build.
05 A news digest of only your topics, hype removed
Scheduled prompt: my three topics, five bullets, skip anything that is an announcement of an announcement. Start in the Claude app's scheduled tasks.

Work

06 A work log written at six pm ✓ running on mine
End of day it writes what you worked on, what finished, and what quietly ate the time. Two minute version and my automated one: the work log guide.
07 Tomorrow's meetings briefed the night before
Scheduled evening prompt against your calendar: who, what they'll want, the one thing to prepare. Needs the calendar connector on.
08 The weekly review that writes its own first draft
Friday task: read my work logs from the week and draft the review, wins first. Five daily logs in, one review out, you edit instead of remember.
09 Follow up nudges for emails nobody answered
Weekly prompt over sent mail: everything unanswered after four days, drafted nudge for each, kind and short. Gmail connector, read first, you press send.
10 Meeting notes turned into a task list automatically
Paste or forward the notes, one saved prompt: owners, deadlines, and what I personally owe. Save it as a Project so the format sticks.

Money

11 Monthly statement roundup, everything recurring listed
Export the statement, one prompt lists every recurring charge with amounts. The exact prompts: the subscription audit guide.
12 Price rise flagger, what quietly got more expensive
Same export, second pass: compare against last month, flag anything that went up without telling me. Two statements in, one list out.
13 Receipts filed into a spreadsheet as they arrive
Forward receipts to one folder, weekly prompt turns them into rows: date, merchant, amount, category. Start manual weekly before automating the trigger.
14 The big purchase interrogation before you buy
Five questions, then an honest answer on whether you need it. The full prompt with copy button: the life admin guide, number five.
15 Renewal warnings two weeks before they hit
Keep one renewals note with dates. Weekly scheduled prompt: anything inside fourteen days, tell me now with the cancel path from the audit guide.

Files

16 The Friday folder sweep, renamed and sorted, nothing deleted without asking
Claude Code over your downloads folder: propose renames and moves, apply only after you approve. The never delete rule goes in your memory file.
17 Screenshots described and filed where you'd actually look for them
Point Claude Code at the screenshots folder: describe each, rename to what it shows, file by topic. Run it monthly, it pays for itself the first time.
18 One naming rule enforced across every project
Write the rule once in your memory file, then a scheduled sweep flags violations instead of fixing them silently. Boring, and it compounds.
19 Scattered notes merged into one organized doc
Drop the fragments into a Project, one prompt merges and organizes with headings, flagging contradictions instead of guessing. Run per topic.
20 A backup check that flags anything missing
Weekly Claude Code task: compare the backup folder against the source, report anything missing or stale. Report only, restore stays manual.

Personal

21 Posts and slides rendered from a text file ✓ running on mine
This whole account runs on it: deck text goes in a file, a build script renders every slide. The pattern: Claude Code plus a template, then the starter guide.
22 YouTube videos watched for you, answers with timestamps ✓ running on mine
A free skill, two commands to install. Paste a link, ask what you want to know: the watch guide.
23 Study quizzes drilled from your own notes
One Project with your material, then: quiz me one question at a time and do not move on until I get it right. Full system: the study guide.
24 Fridge contents turned into dinners and a grocery list
Three dinners under thirty minutes plus the list for the week. Full prompt with copy button: the life admin guide, number one.
25 Packing lists built from your trip dates and the weather
Trip dates, destination, what's booked: a packing list sorted by bag, with the two things you always forget on top. Save yours as a reusable Project.

The honest pattern in all 25: schedule one prompt, keep the output somewhere you already look, and let it run for a week before you trust it. Anything touching money or deletion stays read only until you've watched it be right a few times.
